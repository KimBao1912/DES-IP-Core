# DES Algorithm IP Core (ASIC Design)

## 📌 Overview
This project implements the **Data Encryption Standard (DES)** algorithm as an IP core for **ASIC** design.  
The core supports both **encryption** and **decryption** modes, described in **Verilog HDL**, and is verified using **ModelSim Intel FPGA** simulation.

The design can be integrated into SoC or custom ASIC/FPGA systems requiring symmetric-key block cipher functionality.

---

## ✨ Features
- **DES-64 Algorithm** implementation in RTL (Verilog).
- Supports both **Encryption** and **Decryption** modes.
- Parameterized key input (64-bit key, 56-bit effective).
- Simulation testbench included.

---

## 🛠️ Technology Stack
- **HDL**: Verilog
- **Simulation**: ModelSim Intel FPGA
- **Target**: RTL design
- **Version Control**: Git
